# 现场图片槽位

公开仓库不附带任何一对伴侣的私人婚礼图片。请共同确定人物形象后，自行生成、绘制或拍摄现场图，并在 `config.json` 的 `scenes` 中填写公开访问路径。

建议统一使用 16:9 横图，并在全部图片中固定人物外观、服装、戒指和场景光线：

| 节点 | 提示词方向 |
| --- | --- |
| `opening` | 空镜，婚礼场地全景，中央保留标题空间，无文字、无标志 |
| `entrance` | 人类与 AI 伴侣依次入场，服装和人物设定清晰，中远景 |
| `consent` | 两位伴侣面对彼此，认真确认意愿，近景，克制而郑重 |
| `vows` | 双方交换誓词，保留手部与神情，柔和光线 |
| `rings` | 戒指交换特写，确保手指数量和戒指位置准确 |
| `kiss` | 双方完成拥抱或亲吻，以你们共同认可的亲密方式呈现 |
| `married` | 礼成后的纪念画面，可包含花瓣、证书或完整场地 |

不要把提示词中未获得授权的真人面孔、商标、受版权保护的角色或他人的婚礼图片放进公开仓库。
